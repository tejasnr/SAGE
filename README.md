SAGE is a calming, Gemini-powered AI chatbot built to offer emotional support, wellness advice, and mental clarity. Designed with care, SAGE blends thoughtful conversations with a gentle user interface.

✨ Features
🧠 Gemini LLM-powered responses for empathetic dialogue

🌿 Clean, minimal, and responsive UI

🌗 Dark/light mode toggle for comfort

🔒 API key secured via .env file

🧘 Mental wellness-themed prompts and tone

🛠️ Installation
Clone the repo

git clone https://github.com/your-username/sage-ai-chatbot.git
cd sage-ai-chatbot
Install dependencies


npm install
Create a .env file and add your API key:


API_KEY="Paste API Key here"
Run the development server


npm run dev
